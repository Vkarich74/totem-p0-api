# G5 T6-F — batch readback contract (draft; no release)
Current production remains HOLD. This code is not scheduled. The new flag TOTEM_US_ODOO_SAAS_BATCH_READBACK_ENABLED is default-off and requires the three existing flags; never set it in production without G5 release approval.

One canonical payment evaluator, not a second entitlement authority. Coalesce the individual gate's exact queries by model, domain shape and fields, replay only the exact per-owner result. One authenticated client, serial grouped calls, deterministic id asc paging, bounded 50 owners/100 IDs per query/20 pages/80 RPCs/8s. Unsupported shapes, invalid fields, duplicate/out-of-order/unlinked results, saturated per-owner reads, transport error, incomplete pagination or deadline fail the batch closed; no refresh or definitive revoke on uncertainty. No long-lived mutable provider cache. Oldest batch observation is the evidence timestamp; retain the 10-second transaction receipt check and 300-second access TTL. Both channels use the existing canonical gate, including exact invoice, line, payment, refund and renewal linkage. Deterministic id order also applies to individual reads. Source and commercial approval must already exist.

Existing PostgreSQL queue job type, claim/heartbeat/retry and system audit preserved. Explicit batch worker claims real jobs, begins heartbeat immediately, preloads exact source and existing projection xmin before Odoo. No database transaction held during network. Per-owner apply rechecks source, current xmin and lease row in one transaction; SQL concurrency bounded to four. A failed audit rolls back the projection. No queue migration, no provisioning, email, payment or Odoo writes.

Test scope: populated synthetic JSON-RPC dataset using real client, comparison against canonical single gate, manual/online, hostile and incomplete data, pagination, 50-owner request counts, real PG17 queue with synthetic provider delays and two forced-due cycles (not a live scheduler or sustained Odoo SLA). Full paid live evidence remains unavailable because company4/site5 currently has zero paid subscriptions. Confirm representative full Odoo paid path, real populated throughput and steady-state/failure recovery before periodic wiring. Production runtime credential config, actual payment and commercial approval remain prerequisites.
